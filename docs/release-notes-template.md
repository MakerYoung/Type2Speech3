# 发布说明模板

复制到 `CHANGELOG.md` 的新版本标题下。章节按需保留，没有内容就删除该章节。

```markdown
## [X.Y.Z] - YYYY-MM-DD

### Added

- 新功能 / 新文件 / 新配置项

### Changed

- 行为、默认值、路径、依赖的变化

### Fixed

- 修复的问题（面向用户描述现象，不写提交号）

### Removed

- 删除的功能或模块

### Security

- 安全相关修复（如有）

### Upgrade Notes

- 破坏性变更与迁移步骤（无则写“无”）
```

## 写作规范

1. **一条一行**，以动词开头：新增 / 修复 / 调整 / 移除。
2. 用户能感知的行为优先；纯内部重构归入 `Changed` 并一句话说明。
3. 每条尽量回答：什么场景、原来怎样、现在怎样。
4. 涉及数据目录、配置格式、快捷键语义的变化，必须写进 `Upgrade Notes`。
5. 已知限制写清楚，避免 Release 评论区重复提问。

## 示例

```markdown
## [3.1.0] - 2026-12-01

### Added

- 预设文本支持拖拽排序
- 设置页显示当前数据目录

### Fixed

- 修复切换输出设备后首次播放无声

### Upgrade Notes

- 无
```
